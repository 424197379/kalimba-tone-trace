# 卡林巴循音

Kalimba ToneTrace 是一个面向 21 音 C 调卡林巴的本地优先练习 App。它用下落音符块和独立进度条提示弹奏时机，支持示范播放、自动伴奏、屏幕琴键演奏和本地曲谱导入。

在线使用：

[https://424197379.github.io/kalimba-tone-trace/](https://424197379.github.io/kalimba-tone-trace/)

## 主要功能

- 21 音 C 调卡林巴练习界面
- 下落块、独立进度条和琴键高亮
- 内置单音曲库搜索、难度筛选和最近练习排序
- 全曲库单音主旋律练习，原和弦数据仅保留作来源与兼容备份
- 示范播放和可开关自动伴奏
- 低延迟屏幕琴键，可直接当电子卡林巴演奏
- 本地 JSON 曲谱导入和本地曲库管理
- PWA 安装、离线缓存和手机横屏练习

## 更新到最新版

点击练习页或曲库版本号右侧的刷新图标，可主动检查最新版本。发现新版后会下载并刷新当前页面；更新完成会显示实际版本，当前曲目和本地导入曲谱会保留。已是最新版、离线或下载失败时也会显示提示，可联网后再次点击重试。

已有的“立即更新”提示使用同一更新入口。若刚发布时手机仍未出现刷新图标，先重新打开网页，让页面加载新入口。

从旧版页面首次升级前，先复制尚未保存的导入原稿。新版会把输入原文暂存在本标签页，换曲返回、刷新或更新后可恢复，不上传也不自动导入；关闭标签后不保证保留。暂存失败会保留当前文本并暂停应用内离开。恢复草稿不代表它尚未保存，请先核对本地曲库；具体边界见 `docs/IMPORT_DRAFT_RETENTION.md`。

## 如何练习

### 没有实体卡林巴

可以直接把卡林巴循音当作电子卡林巴使用：

1. 打开曲库，选择一首歌曲。
2. 点击“自己弹”或“听示范”。
3. 直接点击屏幕底部的琴键，App 会播放对应的电子音。
4. 看下落块到达琴键上方的底线，跟着节奏练习。

这种方式不需要额外设备，也不需要实体琴，适合先熟悉旋律、节奏和按键位置。

### 有实体卡林巴

如果你有 21 音 C 调卡林巴，可以把手机横屏放在卡林巴上方，让屏幕里的电子琴键和实体琴键大致对齐：

```text
手机横屏
┌──────────────────────────────┐
│  进度条 / 下落块 / 当前目标   │
├──────────────────────────────┤
│ F3 G3 A3 B3 C4 ... C6 D6 E6  │  ← 屏幕底部电子琴键
└──────────────────────────────┘
              ↓ 对齐
┌──────────────────────────────┐
│  实体 21 音 C 调卡林巴键片     │
└──────────────────────────────┘
```

建议做法：

1. 手机横屏打开练习页。
2. 把手机放在卡林巴键片上方或上沿附近，尽量让屏幕底部琴键对齐实体键片。
3. 点击“自己弹”，按照下落块提示弹实体卡林巴。
4. App 不会申请麦克风权限；它只作为跟谱提示和屏幕电子琴键使用。

较窄的横向练习区会将曲名、暂停和换曲单列一行，避免和听／弹、速度、伴奏按钮重叠。视口同时很矮时会收紧键区与进度留白；电脑浏览器放大后也使用同一适配。练习页和曲库不显示谱面说明或详情下拉；来源及限制保留在仓库说明和歌曲数据中。

如果手机宽度和实体卡林巴不完全匹配，可以在练习区用双指捏合缩放琴键宽度，让屏幕琴键间距更接近实体琴键；也可以点击“键宽 100%”恢复默认宽度。

### 从头、分段与全屏

- 进度左侧的刷新图标：退出分段练习，以当前听／弹模式从全曲开头倒数重来。播放中把进度拖到最左边，松手后也会完整倒数；暂停时拖回起点仍保持暂停，点继续后准备。
- “分段练习”：点开后拖动“起”“终”选择循环范围；再次点击退出片段。
- 已安装离线缓存后，换曲页直接读取当前版本的页面，不再等待一次网络响应；首次打开或缓存不完整时仍需要网络。更新继续通过版本检查和“立即更新”完成。
- 曲库卡面显示曲名、难度、预计练习时间、作者、练习速度与音符数，使用播放图标进入练习；来源说明保留在仓库中，简洁显示名不代表谱面已经重新核准。
- 从曲库换页会结束上一页的浏览器全屏。进入练习页后，点击“自己弹／听示范”会尝试一次全屏；也可点进度条旁的全屏图标。浏览器拒绝时仍可正常练习。
- 网页无法保证隐藏微信等内置浏览器的标题栏。不支持全屏时可在系统浏览器打开，或尝试添加到主屏幕；系统状态栏和手势条仍可能保留。手动退出全屏后不会因旋转或普通播放操作反复抢回。

### 琴键上的预告与持音

- 到音之前，下一键先亮边框，内部仍暗；再下一音用更淡短边线。已有音持续时，它保持实心柔光，下一键用淡轮廓预告。
- 临近起音时，该键提示会短暂熄灭；下落块到达判定线时，键内变为更亮的实心柔光，按谱面时值保持，到音结束才撤掉。灯亮不代表必须反复拨动。
- 连续同键的独立起音会各自短暗，小双线标记表示还需再拨；延音只保持，不新增重拨提示。休止中段没有持音填充，临近后续起音才重新出现预告。
- 暂停冻结当前位置的提示；速度、进度和 A/B 循环与原有播放时间共用，不另设提示时钟。屏幕点键的绿色底边是独立触键反馈。
- 快速音符的短暗按音间隔缩短，低帧率可能略过极短窗；不会为了补看见而在起音后黑一下。减少动态效果设置下不作渐变，主次轮廓与持音填充仍区分。见 `docs/KEY_GUIDANCE.md`。

### 只弹旋律，听与弹分开

- 全曲库不再提供和弦练习入口。旧和弦链接和上次选择会转到对应单音旋律，原源数据仍保留。
- “自己弹”：下落块提示旋律，手机只播放你开启的伴奏，不自动代弹旋律。“听示范”：手机播放同一旋律及所选伴奏。
- 每次点“自己弹 / 听示范”都从当前 A/B 片段的 A 点重新倒数；未开启片段时从全曲开头倒数。点“继续”才从暂停位置恢复。
- 短暂前台掉帧会继续推进画面，已经过时的声音不会集中补响；长中断或显示异常会保留位置并在轨道内显示暂停原因，点“继续”准备后恢复。见 `docs/PRACTICE_FOREGROUND_RECOVERY.md`。
- 点“换曲”立即暂停并取消尚未完成的声音准备；如果新页面未能打开，原位置、速度和循环仍保留，可手动继续。
- 《生日快乐》《小星星》《See You Again》《铃儿响叮当》《青花瓷》《萱草花》提供可关闭的轻伴奏，默认关闭，逐曲记住选择，不增加任何实体琴目标。各自采用的源和减配范围详见对应说明。
- 《小星星》后续已核对所选42音旋律及稀疏支持的和弦归属；早期“仅取共同音、尚未核源”的状态保留在历史记录中。谱面与结构检查不等于主观听感通过，详见 `docs/TWINKLE_SOURCE_2.4.3.md`。
- 早期 A/B/C 试听属于开发对照，旧自动伴奏不作为新的实体和弦任务；当前可用选项以每首曲目的伴奏菜单为准。

### 已核对的局部修正与适配限制

- 《诀别书》保留现有334个单音；历史跨谱复核仅覆盖开头主题，完整15键脚本未单列旋律声部，整段单音取舍仍待核。详见 `docs/JUEBIE_SOURCE_GAP.md`。
- 《声声慢》（戏腔简谱版）明确采用逸兔完整24个实写小节，按真正首尾反复两遍，共252次主音起音、192拍；保留原谱72 BPM，统一E→C移调。明示省略无定时倚音及波音，不挪动主音，详见 `docs/SHENGSHENGMAN_XIQIANG_EDITION.md`。
- 《云烟成雨》已按所选谱逐段核对并修正有证据的延音、音区与节奏，现181次起音、124拍。第28小节整节仍保留旧值待核，其余已核范围与末尾4拍人声休止有明确记录。
- 《告白气球》《起风了》《夜的钢琴曲五》结尾的3拍纯休止会完整走完；循环含结尾时也保留这段呼吸。
- 《天空之城》现选连续高潮段，从后半主题弱起直至原谱收尾：55音、65拍，原谱88 BPM，1倍速约44秒。无拼接、无改音，21音C调无需调音；不含熟悉的开头主题，不是全曲。原录音试听与实体演奏待确认；旧拼接版和旧改音版均完整归档。

### 把难的一小段练熟

- 点击进度条旁的“分段练习”，选中当前位置附近的一小段。拖动“起”“终”调整起止位置，边界会对齐曲谱音符。
- 点击“自己弹”或“听示范”。每次回到 A 前会显示与当前速度同步的准备拍数；A 处的音会播放，B 处的音留给下一段。
- 再点“分段练习”退出，也可以把进度拖到片段外；重置、换曲或重新打开页面时循环默认关闭。
- 初次打开曲目使用 1.00 倍原速，已主动调整过的曲目仍恢复原先保存的速度。调慢只改变节奏，不改变音高；点速度条下方的“1.0”小点可恢复原速。 不同曲目分别保存，避免多个独立页面重叠保存时把另一曲的新速度带回旧值；同一曲仍以最后写入为准。升级到2.4.46后请刷新所有旧练习页和曲库页，旧页不会识别新保存的速度。旧速度在未另行调整前仍可读取，原记录保留；具体边界见 `docs/SONG_SPEED_ISOLATION.md`。
- 主旋律版可以配合自动伴奏使用，你只需弹主旋律。伴奏调到 0% 后不再发出新音，已经弹响的余音自然衰减。

键盘也可操作：进度条方向键移动，A/B 的方向键逐音符调整，Home/End 到边界，Escape 退出循环。

## 在线使用与 PWA 安装

1. 用手机或电脑打开线上地址。
2. 手机建议横屏练习。
3. 浏览器提示安装时，可以添加到桌面或主屏幕。
4. 已安装 PWA 后，联网打开一次会更新离线包；出现“立即更新”提示时点击即可切换到新版本。

如果手机仍打开旧版本，先联网重新打开线上页面，再点击版本号旁的刷新图标，查看检查或下载结果。手机横屏精简练习界面隐藏了版本栏，可通过“换曲”进入曲库更新。无需清空本地曲谱或重新安装。

## 本地启动

需要本机已安装 Node.js（本次验证使用 24.19.0）。运行项目无第三方依赖，无需 npm install。

单音优先2.4.0验收见 `docs/VERIFY_2.4.0.md`，2.4.1源谱定点校对见 `docs/YUN_YAN_TIES_2.4.1.md`、`docs/ENDING_RESTS_2.4.1.md`、`docs/SKY_CASTLE_FIT_2.4.1.md`；全库逐首待核清单见 `docs/SINGLE_NOTE_AUDIT_2.4.0.md`。

```powershell
npm start
```

或：

```powershell
node serve-kalimba.js
```

电脑访问：

```text
http://localhost:8123/index.html
```

手机局域网访问：

1. 电脑和手机连接同一个 Wi-Fi。
2. 在电脑终端运行 `node serve-kalimba.js`。
3. 终端会打印 `Phone on same Wi-Fi` 开头的地址。
4. 用手机浏览器打开该地址。

## 导入本地曲谱

1. 打开曲库页。
2. 点击“添加歌曲”。
3. 复制页面里的 AI 提示词，用简谱照片或已有资料生成 JSON。
4. 粘贴 JSON 并保存。

导入的曲谱保存在浏览器本地存储中，不会写入仓库。JSON 可以只包含主旋律，也可以包含和弦目标音、自动伴奏和节奏休止信息；App 只把已标明的单音主旋律呈现为练习入口，原始编配数据保留备份；无法明确主旋律的多音数据需要复核。

## 许可证与曲谱来源

项目代码开源协作，但现代歌曲曲谱、照片、OCR 中间结果和复核记录可能涉及版权。请不要把未经授权的原始曲谱照片或 OCR 文本提交到公开仓库。

### 录入前的两层检查

曲库“添加歌曲 → 复制提示词”提供最新单音转谱要求。先核对源图中的延音、重复起音、三连音、休止和升降号，再导入 JSON；导入结构通过并不能证明音乐内容保真。新导入错误会明确指出，不会悄悄丢弃非法音符。旧本地曲库兼容读取。

编谱流程与适用的证据检查见 `skills/kalimba-tone-trace-compiler/SKILL.md` 和 `skills/kalimba-tone-trace-compiler/references/evidence-and-regressions.md`；`npm run check` 已包含导入契约和编谱证据回归。

历史试听脚本保护其原先修正范围。后续版本重做2.4.1的三组延音对照时，使用 `render-tie-comparison.py --before-zip <2.4.0源码ZIP> --after-zip <2.4.1源码ZIP> --output <仓库外目录>`；不会把后来新增修正冒充旧试听。

### 2.4.5 两首易曲

《送别》第7–8小节五音按已核来源回到较低音区，其他时序和后续相似句不改；第3–4小节及后半段仍待核。《蜜雪冰城主题曲》前奏第5小节只需弹一拍C5，随后一拍省略源谱琶音和弦；这是一处单音改编空档，并非原曲全部声部休止。两曲旧伴奏暂不使用，继续直接练单音。

完整来源和差异见 `docs/FAREWELL_CADENCE_2.4.5.md`、`docs/MIXUE_MELODY_2.4.5.md`。源谱BPM、旧曲谱建议倍率与实际选择/记忆的播放速度是不同信息，验收记录以实际倍率为准。

### 2.4.4 茉莉花短版

《茉莉花》（短版）采用黄秀泉署名的14小节谱，完整56拍、67个单音，适合先练完整主题。选曲卡和练习页只展示当前短版及来源说明。旧链接和已有速度记忆沿用，循环和进度不保留。

短版不再借用旧长版伴奏；《星际穿越》修正后也不再借用不匹配的旧V2伴奏。来源没有提供可核对的适配伴奏时，可直接练单音。完整依据及恢复方式见 `docs/JASMINE_SHORT_2.4.4.md`。

### 2.4.3 定点校对范围

《星际穿越》第44–49小节恢复所选谱的真实三连音，仍是困难尾段，建议慢速、分段练习。前段声部、音区和变拍显示仍待完善。详见 `docs/INTERSTELLAR_TAIL_2.4.3.md`。

《生日快乐》保留原单音旋律与延长记号的固定拍处理，只按首来源和弦位置校正轻伴奏三个低音/和声音。轻伴奏仍可关闭，无需在实体琴上弹和弦；它是稀疏编配，并非原谱逐音伴奏。详见 `docs/BIRTHDAY_SUPPORT_2.4.3.md`。

### 2.4.2 曲目校对范围

《云烟成雨》采用所选发布者31小节单音主旋律范围，保留最后4拍旋律休止。第28小节整节仍为旧版，音高与节奏待核，选曲和练习页面都会说明。其余已确认修正与历史来源、实际验收见 `docs/VERIFY_2.4.2.md`；不代表全库或所有编配已保真。

### 2.4.6 大雨小雨节奏

按既有公开源谱修复第9、10小节被拉长一倍的节奏。70次起音和全部音高保持，主题一次为11小节44拍；另列括号间奏继续省略。92 BPM 是练习基准，谱面未标速度。详情见 `docs/RAIN_TIMING_2.4.6.md`。

### 2.4.7 选曲时长

### 2.4.11 暂停与继续（本地预览）
