## 实体键位计算方法

实际左至右键序：

`D6 B5 G5 E5 C5 A4 F4 D4 B3 G3 | F3 | A3 C4 E4 G4 B4 D5 F5 A5 C6 E6`

左侧 0—9 与右侧 11—20 用作通常分手方式的近似；中间 F3 不硬指派拇指，本库没有 F3 旋律起音。左右手交替是计算模型，不是强制指法。实际手型、琴键间距、扫弦及跨手选择需真人验证。

- 相邻起音间隔 = 相邻 beat 差 × 60 / BPM / 速度倍率。
- “快”在本报告仅指 **间隔小于 250 ms** 的描述性筛选；不是人体极限或初学者合格线。
- “同侧移动”排除同音重弹。单侧跨 3 个或更多 lane 的移动另记；跨左右两侧的大 lane 差不能当成同一拇指横跨整把琴。
- 原界面首次无保存速度时为 **0.55x**，不是 JSON 的 `defaultSpeedFactor`。后者是用户点击“曲目默认”采用的倍率。已保存速度会覆盖首次慢练值。
- 修正三连音后，1.0x 下有 **796 次 / 20 首**相邻起音短于 250 ms，其中同音重弹 **138 次 / 10 首**，同侧异音移动 **154 次 / 15 首**。在 0.55x 下分别为 **78 次 / 5 首、21 次 / 2 首、20 次 / 3 首**。
- 1.0x 下，同侧相邻音跨至少 3 lane 且间隔短于 500 ms 共 **54 次 / 10 首**；若允许中间穿插另一手，按每侧自己的连续起音计算，则为 **60 次 / 11 首**。这些是复练定位，不能作为删音依据。

## 优先处理的保真缺口

1. **天空之城：有记录的半音替换。** `sourceFeatures.unsupported` 明载 #4、#5 被邻近自然音替代；这与当前“不能替换关键半音”的编译规则冲突。源页面可读取，但本轮原图请求未成功，尚未定位这些音属于主旋律还是省略声部。下一步先取清晰原图，逐处确定。若主旋律无法整体移调适配自然音琴，应标范围受限或改选忠实片段，不能再自然化。
2. **云烟成雨 / 星际穿越：有记录的节奏量化。** 云烟成雨仅本次 3 音已修；其余小节仍未重编。星际穿越 m44—49 备注明确将三连音改为 0.25 拍。现代编译器已经能保留三连音，不能继续以避免网格警告为理由改写节奏。
3. **来源或分组缺口。** 茉莉花 m25—30、大鱼 m7/15—16/30、喀秋莎拍号/反复、天空之城 m15 连线、太阳照常升起 m9 来源冲突应逐处核对。青鸟简化副歌、菊次郎拍号推定、青城山低音点等应清楚限定范围，不能当作全曲错谱结论。
4. **显示范围和真实谱面边界不同。** 梦中的婚礼已有真实 `meterMap`，全局 4/4 不能表示源谱变拍；星际穿越也有 3/4→4/4 来源说明。告白气球、夜的钢琴曲五各在第 129 拍结束发声而谱面到 132；起风了为 77/80，均漏出最后 3 拍纯休止。后续可让进度/循环采用可靠的源谱结束界限，不能通过拉长末音补齐。

## 两项低风险界面/练习流程建议

### 1. 防止短音被 120 ms 提前换灯跳过

审计开始时 `getJudgementEvent` 取进入固定 120 ms 提前窗口的最新事件。在 1.0x 的 **22 次起音**，下一个事件已进入该窗口：告白气球 16 次、夜的钢琴曲五 6 次。也就是当前音恰好应弹时，判定对象已经变成后一个；其中 4 次为同音同键，另 18 次会指向不同键。在 1.4x 下共有 181 次事件被提前替代，涉及 8 首。首次 0.55x 下没有此类相邻间隔。

建议把每个音的提前量限制为其与前音间隔的适当比例，确保上一音在自己起音点仍有明确灯位；或者分开“此刻拨弦”与“下一音预告”。只改提示时机，不改任何谱面起音。用本库上述两首的实际三十二分/三连音事件、同音重弹、暂停/拖动/循环边界做回归。

### 2. 显示可操作的复练信息，保持谱面原节奏

在既有适配详情中明确“源谱待核 / 所供选段 / 实体琴未试听”，并以实际速度显示紧邻的重复音或同侧转换。可将这些位置直接交给现有 A/B 循环，而不是自动删音、平均分拍或默认宣称准确。

典型优先复练位置：

- 告白气球：C5@36.5→36.625，同键间隔 83 ms；0.55x 仍为 152 ms。
- 夜的钢琴曲五：57.5—58、121.5—122 两组 C4→E4→G4→D5，右侧 lane 12→13→14→16；间隔 83 ms，末一步越过 B4 的 lane，不能笼统提示为“连续相邻扫弦”。
- 别看我只是一只羊：17 次同音短间隔，源速 125 ms；0.55x 为 227 ms。
- 平凡之路：A4→G5，beat 26.5→26.75 及 90.5→90.75，同左侧跨 3 lane，源速约 179 ms。

这些位置适合慢速循环与先看后弹；更好跟弹是界面目标，能否轻松弹奏仍须由实体琴验证。音块最小高度会使同列快速重复相互覆盖，若做视觉优化应保留每次独立起音及八度标识，不可合成一个长音块。
