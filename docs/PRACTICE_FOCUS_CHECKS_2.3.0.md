## 本地运行

解压完整源码后安装 Node.js，进入项目目录执行 `npm start`，打开 `http://localhost:8123/index.html`。不需要安装额外 npm 依赖。

若使用补丁，在准确基线的干净仓库中先运行 `git apply --check kalimba-practice-focus.patch`，再自行决定是否应用。此预览不执行推送或部署。
