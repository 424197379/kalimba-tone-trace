# 琴键上的预告、短暗与持音

2.4.47 本地预览新增屏幕琴键提示。音符数据、音频派发、下落块的位置计算、速度和键宽校准不变。

## 看法

- **提前预告**：下一音是清晰边框，内部保持原来的暗色；再下一音是更淡的短边线。
- **正在持音**：已经起音的键变成更亮的实心柔光，保持到谱面时值结束。下一音仍以较淡轮廓预告。
- **临近起音**：仅该键的指导短暂熄灭，到起音点再填充。持续亮不表示不断重拨。
- **同键重复**：两个短横线表示后面还有一次独立拨音；真正的延音没有额外重拨。独立重拨前的短暗可以覆盖同键前音末端，其他正在持音的键不受影响。
- **屏幕试听**：绿色底边是触键反馈，与跟谱指导独立。

## 时间规则

预告窗取当前一拍的秒数，限制在 0.45–1.2 秒内，并且不超过下落块的可见提前量。每个未来起音分别检查此窗口；不会因为第一音临近就提前亮很远的第二音。长休止中段和末尾不保留已结束键。

短暗最长 60 毫秒，同时不超过前一个不同起音间隔的 20%。密集音符会缩短短暗；低帧率可能跨过极短窗口。不会在起音以后补黑，也不为提示改变音符时间。减少动态效果偏好下不作渐变；离散的预告、短暗和填充仍保留。

持音采用谱面半开区间：起音时开始，`beat + duration` 时结束。合法导入若有重叠时值，所有尚未结束的键都保持填充；这只是显示，不增加和弦判定或实体琴目标。循环仅接受 A 内、B 前的起音，并在 B 截断显示；不提前亮循环外的音。

## 暂停、继续与定位

纯选择器以实际练习时间和当前速度计算提示，不使用独立定时器。暂停冻结已显示的亮或暗；首次/A 准备被中断后的“继续准备”显示尚未起音的稳态轮廓，直到真正开始才填充。中途长音恢复继续保持已起音的键，不新增重拨。

显示层只锁存已经进入的短暗，避免调速后同一音先亮回去、再灭一次。锁存到该起音即解除；换曲、范围变化、向后定位和新一轮循环会重新选择，拖进度不会补闪过去的音。停止状态下定位到短暗窗只显示稳态目标，不主动启动一轮短暗。

## 验证边界

生产渲染测试把同一时刻的块底边、判定线、琴键填充和旋律派发放在一起核对。这证明应用逻辑共用时间线，不等于设备实际扬声器瞬态或蓝牙延迟为零。原采样和音频调度未为了视觉特效裁剪、提前或延后；本轮不声称实体琴或全库主观听感已经验收。
