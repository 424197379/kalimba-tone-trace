## 已落实的用户价值

- 云烟成雨：对原发布者说明及源图逐处核对，合并3组同音延音，保留不相连的重复音，并修正第4小节末节奏。199→196起音，190个无关元组保持不变，总时值110.5拍、结束第120拍不变。
- 三首曲目的末尾3拍纯休止：使用既有可靠sourceTotalBeats，不补音、不拉长末音；循环和曲库时长采用相同界限。
- 休止视觉：写定延音期间保留当前列，真正休止内不亮当前键，也不因下一音预告窗口提前点亮。浏览器实际检查《起风了》末音区为1列亮，进入尾休止后为0列/0键亮。
- 天空之城：独立出版社谱面确认原主题主旋律包含升4/升5，固定自然音琴无法保真覆盖该完整主题。选曲处明确“改音版”和限制，既有79音不被悄悄替换，原2019编配全图仍待核对。
- 项目编谱skill与对外AI导入提示词：同步源证据、连线/重复音区别、精确三连音、尾休止、半音适配和单音安全提取，配结构校验。结构正确不等于源谱正确，不声称自动杜绝转写错误。

## 源证据与检查范围

见 `YUN_YAN_TIES_2.4.1.md`、`ENDING_RESTS_2.4.1.md`、`SKY_CASTLE_FIT_2.4.1.md`。不把独立教材不同的节奏拼进旧天空之城编配；不因一次局部校对把云烟整曲升级为推荐。

云烟听辨文件为真实采样、69 BPM、1.0倍速、相同增益的前后干混音。A旧版0–16.559秒，停顿1.5秒后B修正版从18.059秒开始；总长34.618秒。其变化仅为3次多余攻击消失及末组E5/C5各提前1/4拍；不是电子延音合成。用户明确认可本次修正的听感，仍不等于全曲或实体琴验收。

## 使用与复现

解压进入项目目录，运行 `npm start` 后打开 `http://localhost:8123/index.html`。运行只需Node.js，无需安装依赖；完整检查为 `npm run check`。

原采样离线对照渲染是可选开发工具，另需Python、NumPy、ffmpeg/ffprobe；它们不是运行App的依赖。重做本次前后对比时，给 `scripts/render-tie-comparison.py` 的 `--before-zip` 指向保留的2.4.0源码ZIP。后续源码版本重做本历史试听时，还需 `--after-zip` 指向冻结的2.4.1源码ZIP，避免把后续修正混入原对照。
