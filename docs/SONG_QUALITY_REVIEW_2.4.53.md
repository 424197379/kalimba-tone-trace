# 《天空之城》MV 短版核对

本次替换主旋律数据，沿用原曲目 ID、界面和播放实现。旧 V2 来源记录保持不变，因旋律与时序不再匹配，不为新短版提供伴奏。

## 范围与时长

- 主依据：用户提供的[比三呆弹吉他 2018-08-28 两页简谱](https://mp.weixin.qq.com/s/Sf9pW8EZ9ezs92oSP4w5-A)。
- 取源谱第 1—6 小节、第 7 小节前三拍，接第 9 小节最后一拍至第 15 小节，再接第 17—33 小节。保留开头主题、回应乐句和后半主题收尾，两处为短版剪接，不是原曲连续选段。
- 源谱第 8、16 小节简化了原有半音，本次均不收录，不用邻近自然音代替。
- 保留开头弱起、第 5、7 小节休止、后半主题附点及末尾 A4 四拍延音；未添加重复乐句或编造终止句。
- 共 120 拍、98 个主旋律起音，音域 D4—A5，全部是 21 音 C 调琴已有自然音。
- 保留原谱 88 BPM，默认 1.0 倍速约 81.82 秒。含谱内三拍起始留白，不含启动倒计时、录制片头及播放器结束余量；未通过减速凑时长。
- 仅练单音主旋律，省略谱上低声部与第 19 小节上声部 D5 下同时发出的 B4。第 15 小节 C5 的连音合并为一个 2.5 拍起音；后半段独立重复音仍分别起音。

## 交叉核对

[Kalimba Class](https://www.kalimbaclass.com/tutoriales-para-kalimba/castle-in-the-sky-kimi-wo-nosete-carrying-you-laputa-joe-hisaishi) 与[音伴 C 调版](https://www.yinban.com/tab/finger/2299.html) 用作独立音高、轮廓与半音位置参照。不同编配的装饰、伴奏和起音并不完全一致；本次全部节奏以用户给出的两页数字简谱为准，不拼用其他版本的节奏。网页的纵向专用谱与数字谱对半音的标注不一致，冲突小节已排除。

## 验证与限制

关键乐句回归覆盖：开头休止、剪接位置、连音、最终终止句、音域与默认时长。替换前，旧数据在 88 BPM 与 120 拍断言处失败，替换后通过。测试只保护已核对的编配决定，不能自行证明源谱正确或剪接好听。

`validate:songs` / `build:songs` / `check` 的结果和浏览器完整播放检查记录在本次私有核对记录中。其余 56 个版本 JSON 保持不变。

本地验收：`npm run check` 通过；运行时 2339 项通过、9 项因缺少其他曲目的私有源谱夹具跳过，编译技能 16 项通过。浏览器以 1.00 倍完整示范 98 个起音，采样音名逐一匹配，最大相对起音误差约 18 毫秒，无页面错误。手机横屏无横向溢出，离线重新加载仍为 88 BPM、98 音的新版本。曲库与结束进度包含播放器尾音余量，显示约 1:23。

旧主旋律逐字节保存于 `data/archives/tian-kong-zhi-cheng-v2.4.52.json`，SHA-256 为 `87cec5397ef34eb01264939c1e15d3e2f2649ec28c678566a59968a9d783b1a6`。实际导入器可将它恢复成独立本地歌曲，不覆盖新内置曲目；日常曲库不增加旧版入口。完整主题含固定 C 调琴缺少的半音这一限制仍成立，历史源谱与复核说明保留在归档和当前元数据的历史记录中。

格式和源谱核对不等于真人试听。剪接听感、实体琴换手与高音余韵仍需要实际演奏确认；适配状态记录为 `conditional`。原始谱图、网页下载件、私有编译与核对记录不加入公开提交。
