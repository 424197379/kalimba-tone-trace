## 根音与省略的含义

固定 F3–E6 自然音音域内，每个根音选择其最低可用音：C4、F3、D4、G3。来源没有带八度的低音声部，所以这是符号导出的配器选择，不是假称全体低声部经同一八度变换，也不是把某个已写出的低音逐音折八度。

每个事件只留根音，完整和弦其余音级全部省略：

- C 省略 E、G
- F 省略 A、C
- D7 省略 **F#**、A、C
- G 省略 B、D
- G7 省略 B、D、F

尤其第 7 小节来源 A7 经 +5 变成 D7，根音 D 本来就是它的成员。删去 F# 不等于把 F# 改成 F；候选从未在该位置加入 F 来替代它。但三音、七音和副属和弦色彩确实不再完整，不能称为忠实再现全部和声或完整 D7。

应用拍 10 和 42 的 F 变化是真实存在的，只省略那两次支持攻击。这样维持每小节一枚根音，并避免只隔两拍就让新 F3 采样尾部进入后续 C 和弦。前一个 C4 在 F 区间衰减时，C 仍是 F 的和弦成员。这个减配不授权把源和弦标成未改变，也不要求填满其他空隙。

精确支持元组为：

```text
[C4, 0, .75]   [C4, 4, .75]   [C4, 8, .75]   [C4, 12, .75]
[F3, 16, .75]  [C4, 20, .75]  [D4, 24, .75]  [G3, 28, .75]
[C4, 32, .75]  [C4, 36, .75]  [C4, 40, .75]  [C4, 44, .75]
[F3, 48, .75]  [C4, 52, .75]  [G3, 56, .75]  [C4, 60, .75]
```

全部 0.75 拍的完整写定区间都位于对应源和弦内，不只是起点合法。16 次支持共 12 拍写定长度。相邻根音最大跳进 7 半音，每次均低于正在发声的旋律，没有同拍同音重复，也没有更改实体手序。

需单独检查的来源音程包括：拍 20／52 的 C4 对 F5（十一度，来源 C5 旋律对 G 和弦），拍 24 的 D4 对 E5（九度，来源 B4 对 A7）。它们是源谱已经具有的旋律／和弦关系，不能为了消除张力而改旋律或自然化升音。拍 28 是 G3 对 D5，拍 56 是 G3 对 G5，最后拍 60 是 C4 对 C5；这几个收句不能混成一套。

## 写定时段、采样本体与效果尾部是三件事

旋律连续覆盖 `[0,64)`；第 4、8、12 小节后的逗号状换气标记没有定量休止值。末旋律 C5@60 持续 4 拍，到 64 结束。末支持 C4@60 写定 0.75 拍，到 60.75 结束。没有添加结束音、重拨、尾休止或额外谱拍。来源没有低音谱表，不能把支持事件之间的空隙冒充原谱低音休止。

实际样本路径播放完整解码 buffer，0.75 拍不会截断样本；`durationSeconds` 对合成器回退有意义，对正常采样播放不是截尾指令。数据阶段只读 ffmpeg 解码所得 C4／F3／G3 各为 1.896 秒，D4 为 1.968 秒；浏览器解码与完整输出必须另核。

以 80 BPM 为基准的 0.55x、1.0x、1.4x 数值检查中，16 个原采样 buffer 的全部 48 个时段都保持根音的源和弦成员关系：

- 0.55x：原 buffer 不跨入其他和弦区间。
- 1.0x：C4@8／40 到 10.528／42.528，跨入 F，但 C 仍是成员。
- 1.4x：上述 C4 到 11.5392／43.5392，同样在 F 内。其余原支持 buffer 都在下个真实和弦变化前结束。
- 最后 C4 的原 buffer 分别到 61.3904／62.528／63.5392，未超过 64。这不代表完整效果尾部也在 64 前停止。

应用还经过约 0.55 秒卷积脉冲响应、低通及压缩。因此上述 buffer 成员检查不能证明完整声音不跨和弦，也不能证明听不出冲突。按 buffer 加名义 IR 时长，1.4x 的 F3@16／48 可能进入后续 C，C4@52 可能进入 G7，最后 C4 可能在 64 后有约 0.303 秒效果余响；实际尾部幅度及完整图输出由独立音频诊断检查。压缩器释放时间是控制参数，不等于额外生成固定时长的声音。

不要裁剪 PCM、改源拍长或增加重拨来制造测试通过。谱外自然余响与新增谱拍不同。浏览器完整图数值检查、源速度／实际练习倍率和可听效果的后续结果，应记录在对应集成验证中；此数据文档不把离线 buffer 检查升级成已完成的听感验收。
