## 验证证据

- 逐小节转写断言：159个小节全部为4拍；休止保留为时间间隙，同音延音合并，全部854个旋律事件通过音域检查。
- `npm run validate:songs` / `npm run check`：45个版本、6038个目标音，0错误。七首曲目的关键乐句回归及适配规则检查通过，包含本批五首的起拍、八度、跨小节延音、细分节奏与尾音。
- `npm run build:songs` 生成曲库；与上一提交按歌曲对象比较，原有40个版本的数据保持一致。
- `npm run report:rhythm` 和 `npm run report:suitability` 完成。本批没有自动伴奏，不存在用伴奏填塞休止的问题。
- 本地 Chromium 逐首以1.00x示范播放，检查开头及特定风险乐句，共103次真实采样起音；21个采样均解码成功，播放节点处于 running、PCM 非静音，音高顺序匹配编译数据，所测起音偏差最大58毫秒。风险位置覆盖三连音、三十二分音符和跨小节延音。这是浏览器运行检查，不等于原演示盲听或实体琴验收。
- 手机尺寸曲库搜索逐首匹配，点击《告白气球》能进入对应练习页，生成226个音块和21个琴键。

## 校验提示与实际限制

校验共104条提示，其中6条为既有提示，本批新增98条：72条来自三连音、三十二分与附点时值不属于四分之一拍网格或时值较短；2条来自纯休止尾小节；24条是曲目长度、左右琴键跨度及跳转提醒。对应谱面细分节奏和高音点已复核，未为消除提示而改写音符。

《夜的钢琴曲五》《告白气球》的谱面各132拍；V1 以最后音符结束定位曲长，两首最后的音符结束于129拍，末尾3拍纯休止仅在来源元数据中记录，播放器使用既有结束余量。没有把休止伪装成长音或重写播放器。

《那个夏天》《戒网》《告白气球》最高音涉及 D6/E6 或大幅左右换手，细分节奏也增加手指难度。实体琴高音音色、长音自然衰减及与原演示对比的主观辨识度仍待实际体验；`sourceFeatures.suitability` 保留这些条件。

本次不包含《漠河舞厅》和《海德薇变奏曲》；两者仍有谱源或默认21音琴适配问题，未以猜测旋律补入曲库。
