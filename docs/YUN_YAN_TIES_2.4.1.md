# 2.4.1 云烟成雨三处延音与第 4 小节结尾定点复核

日期：2026-10-12。范围为第 2—4 小节的三组同音连线，以及复核过程中独立确认的第 4 小节末三音时值，未重编全曲。保留 2.4.0 已修正的开头高音 3—4—5 三连音。

## 来源与判断

核对原编配作者“比三呆弹吉他”的 [发布页](https://www.sohu.com/a/274931646_759018) 与 [第一张简谱](https://5b0988e595225.cdn.sohucs.com/images/20181113/3696afe6f91f4067999b5f0c48daad10.jpeg)。页面明确说明：连线只弹第一个音，后面的半透明数字不另弹。实看原图及放大局部，三组连线的两端音高一致，后端均为灰色；不是应另起音的重复音，也不是异音连奏。

原谱为 `1=C`、`4/4`、四分音符 = 69。以下 beat 从 0 开始，元组为 `[音高, 起音拍, 时值]`。

| 位置 | 原元组 | 修正元组 | 可见依据 |
| --- | --- | --- | --- |
| m2 | `[D5, 5.75, 0.25]` + `[D5, 6, 0.5]` | `[D5, 5.75, 0.75]` | 高音 2 的前端双下划线、灰色后端单下划线；0.25 + 0.5。 |
| m3 | `[C6, 9.5, 0.5]` + `[C6, 10, 1]` | `[C6, 9.5, 1.5]` | 两个 1 都有双高音点；前端单下划线、灰色后端无下划线；0.5 + 1。 |
| m4 | `[A5, 13.5, 0.5]` + `[A5, 14, 1]` | `[A5, 13.5, 1.5]` | 高音 6 的前端单下划线、灰色后端无下划线；0.5 + 1。 |

m2 的 `D5@6.5` 是后续黑色数字，没有接续连线，保留独立起音。不能把其他相邻同音一并合并。

## 拍数和不变量

- m2 为 `[4,8)`：各节拍占用之和 `0.5 + 0.5 + 0.5 + 0.25 + 0.75 + 0.5 + 0.5 + 0.5 = 4`。合并后的 D5 到 6.5 结束。
- m3 为 `[8,12)`：`0.5 + 0.5 + 0.5 + 1.5 + 0.5 休止 + 0.25 + 0.25 = 4`。C6 到 11 结束，保留 `[11,11.5)` 的半拍休止。
- m4 为 `[12,16)`：`1 + 0.5 + 1.5 + 0.25 + 0.25 + 0.5 = 4`。A5 到 15 结束；第 5 小节 G5 仍在 16 起音。
- 199 次起音变为 196 次。三组延音原有 6 个元组合成 3 个，另调整结尾 3 个元组；其余 190 个旋律元组完全不变。没有改变音高、速度、全局起拍或后续小节边界。
- 全部音符时值合计仍为 110.5 拍，最后发声结束仍为第 120 拍。该总数不表示整曲源谱逐音核验通过。

## 单独确认并修正的 m4 结尾

放大图中，m4 结尾高音 `4—3—1` 的第二条下划线只覆盖 4 和 3，因此原谱时值为 `0.25 + 0.25 + 0.5`。原数据为 `0.5 + 0.25 + 0.25`：三音合计同为一拍，但内部起音位置不同。该判断已独立复看源图并单独记录：

- 原：`[F5,15,0.5]`、`[E5,15.5,0.25]`、`[C5,15.75,0.25]`。
- 修正：`[F5,15,0.25]`、`[E5,15.25,0.25]`、`[C5,15.5,0.5]`。
- 保留三个音高、全部三次独立起音和 `[15,16)` 区间。三个数字各有一个高音点；本组没有连线，不作合并。

这项修正依据下划线的实际覆盖范围，不是为凑满小节而重新平均分配。
