# 2.4.0 单音优先：交付与验证

本地预览，未推送或发布。基线 `73041efc803b6c4f16046c8fc0ceaefc08fcc507`（2.2.27）；工作分支 `local/practice-focus`。保留 2.3.0 阶段的循环、准备拍、速度记忆和窄屏修复。

## 使用

解压后在项目目录运行 `npm start`，打开 `http://localhost:8123/index.html`。只需已安装 Node.js（本次用 24.19.0），没有运行依赖，无需 npm install。检查用 `npm run check`。原始和弦 JSON 保留备份，产品曲库只提供 36 首单音练习。

选择歌曲后按“自己弹”看块弹实体琴，或“听示范”让手机播放旋律。两首轻伴奏在菜单里可开关，不增加要弹的琴键。播放中切换听/弹保留位置；暂停后的自己弹继续，听示范重新示范当前片段。片段循环与速度操作见 README。
